SACNM FRONTEND UPLOAD
=====================

Upload file: SACNM-frontend-upload-single-domain.zip
Target website: https://sacnm.com
Confirmed document root: ~/public_html/sacnm
API configured in this build: https://sacnm.com/api

CONTROL PANEL METHOD
--------------------
1. Open the File Manager for the main sacnm.com website.
2. Go to its document root: public_html/sacnm.
3. Upload SACNM-frontend-upload-single-domain.zip.
4. Extract it directly inside the document root.
5. Confirm index.html and the _next folder are directly in the document root.
6. Do not delete the existing public_html/sacnm repository folder because
   api.sacnm.com uses sacnm/backend/public.

SSH METHOD
----------
From the repository root after pulling the latest main branch:

  cd ~/public_html/sacnm
  git pull origin main

Extract the archive into the confirmed main domain document root:

  unzip -o deployment/SACNM-frontend-upload-single-domain.zip -d ~/public_html/sacnm

Install the protective Apache rules because the Git repository and website
share the same document root:

  cp deployment/MAIN-SITE-HTACCESS.txt ~/public_html/sacnm/.htaccess

Then visit:

  https://sacnm.com
  https://sacnm.com/account/
  https://sacnm.com/admin/
  https://sacnm.com/api/health

Never extract the archive into the backend/public directory.
